## A quieter companion and a more comfortable atlas

- Adjust journal scale (**65–115%**) and speech-card scale (**65–125%**); both default to **85%**.
- Set speech opacity (**25–100%**), hide speech cards, or disable automatic remarks independently of manual conversations.
- Choose a minimum automatic-remark interval of **2–30 minutes**, default **10 minutes**. Remarks need a fresh personal or world event.
- Remove achievement statistics, congratulatory spam and random idle remarks.
- Drag the atlas with the left mouse button and zoom around the pointer with the wheel. Marker selection and keyboard controls remain available.

Open **G → the sliders icon** to change these settings. Visual preferences stay
on your computer; the automatic-speech preference and interval persist per player
in the world. Panning does not reveal unknown terrain.

### Install or update

Minecraft **26.3**, **Fabric Loader 0.20.1+**, Fabric API (tested with
**0.165.0+26.3**) and **Java 25**. Put `wicklen-chronicles-0.4.2.jar` in `mods/` on
both client and server, replacing the older Chronicles JAR. The `-sources.jar`
is for developers. Keep existing world data and personal settings.

Gateway of Doom remains optional for courtyard battles. An LLM provider is
configured separately on the server; API keys and private configuration are not
included in release assets.

This JAR matches Chronicles in the published Wicklen pack 0.4.2. Download the
[complete pack from wicklen.link](https://wicklen.link/#download) when joining
that server. Each release includes `SHA256SUMS.txt` for its two JAR files.
