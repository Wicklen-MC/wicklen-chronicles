# Wicklen: Chronicles 0.4.4

Minecraft **26.3**, Fabric Loader **0.20.1+**, Java **25** and Fabric API.

- The floating spirit no longer produces movement sounds from Presence Footsteps.
  The optional integration disables its footstep generator for both the current
  spirit ID and the retained legacy ID.
- Presence Footsteps remains optional. Without it, the spirit keeps its existing
  silent behavior.

Install the same Chronicles version on client and server. Remove the old
Chronicles JAR before copying the new one. The sound fix takes effect on the
client. Existing worlds, journals, discoveries and settings are retained;
no world migration or new required dependency is introduced.

Mochi Pets fixes belong to the separate Wicklen Pack Compat adapter and are not
part of this Chronicles release.
