# Wicklen: Chronicles 0.4.3

Minecraft **26.3**, Fabric Loader **0.20.1**, Java **25**.

- A cloth wanderer spirit: ivory hood, dark face, glowing persona-colored eyes,
  teal patches, a layered cloak and two animated ribbons. The speech portrait matches.
- Two sliders in **Journal → Settings** position spirit speech horizontally and
  vertically. Values are saved on this client; existing settings keep the lower-left
  position. Reset restores the original placement. The card stays above the hotbar
  and the settings window fits small viewports.
- Manual conversations can explain vanilla mechanics using ten bundled reference
  topics and recipe data from the running server. Follow-up questions retain context;
  unknown world locations and unverified mod mechanics are not invented.

Install the same Chronicles version on client and server. Existing worlds and local
presentation preferences are retained. No world migration or new required mod dependency
is introduced. Game help uses the existing configured LLM provider; it is not an offline
encyclopedia and does not yet include third-party mod documentation.

Published player and source JARs and SHA256SUMS.txt are built by the release workflow.
