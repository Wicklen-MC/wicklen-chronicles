## Personal field atlas

- Give discoveries personal names and notes while preserving their original species or place.
- Chart real surface terrain as you travel, with personal markers and fog over unexplored areas.
- Start **First Light**, a short expedition with a survey or courtyard-trial approach and explicitly claimed supplies.
- Record meaningful repeat encounters with a species in a different location.
- Read companion speech in a themed private HUD card, with the full conversation kept in the journal.

### Install

Minecraft **26.3**, **Fabric Loader 0.20.1+**, Fabric API (tested with
**0.165.0+26.3**) and **Java 25**. Install the regular `wicklen-chronicles-0.4.0.jar`
on both client and server. The `-sources.jar` is for developers.

Gateway of Doom is optional and enables courtyard battles. LLM conversations
require a separately configured server-side provider; credentials are not bundled.

This historical version is retained for reference. Use **0.4.2** for the current
Wicklen pack. Keep client/server mod versions matched and remove the older mod
JAR when replacing it. This release contains the mod, not the complete modpack.
